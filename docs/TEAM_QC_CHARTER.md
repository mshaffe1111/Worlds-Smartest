# World's Smartest — Studio Quality Control & Per-Member Accountability Charter

**Baseline Player Rating (Pre-Overhaul):** `46 / 100` (Direct playtest by Executive Client on `http://localhost:8088`)  
**Release Gate Target:** **`>= 88 / 100`** across every category, **0 Blockers**, **0 Console/WASM Errors**, **0 Unexplained Mechanics**.

> **Core QC Law:** Passing a JSON schema check or a headless `EXIT 0` script is **NOT** quality control. Every deliverable is judged strictly through the eyes and ears of a **first-time human player** playing on Mobile (`390x844`) and Desktop (`1280x800`).

## 2. Mandatory 5-Step Release Gate (No Shortcuts Allowed)

1. **Gate A — Audio Quality Gate (`voice-audio-director` → `qa-art-critic`):** Real studio/sampled music & warm SFX verified via FFmpeg loudness/spectral probe (`0` NumPy synth, `0` clipping).
2. **Gate B — Engine & Automated Logic Gate (`godot-aaa-director`):** Godot 4.7.2 `--import` (`0` errors/warnings) + `--self-test` (`0` leaks, `0` missing glyphs, `ShuffleFairnessOK`, `NoPreselectOK`, `CategoriesModeOK`, `DifficultyCurveOK`, `DirectSliderOK`, `DailyResetOK`) + Web export `index.pck <= 25 MB`.
3. **Gate C — Independent 100-Point Scorecard (`qa-art-critic`):** Live GPU frames of all screens + audio verification -> **must score `>= 85/100` with 0 blockers**.
4. **Gate D — Executive Producer Live Browser Playtest (Coordinator + `browser` subagent):** Full interactive Mobile (`390x844`) + Desktop (`1280x800`) test clicking through Title, Campaign Hub, Categories Picker, Classic One-Tap Q&A, Direct Estimate Slider, Lightning T/F, Q3 Category Fork, Q5 Final Wager, Daily Mode, and 3D Globe — inspecting **every single screenshot pixel-by-pixel** with `0` console errors.
5. **Gate E — User Approval Before Production Deploy:** Invite the user to playtest `http://localhost:8088/index.html` and only push to live GitHub Pages (`https://mshaffe1111.github.io/Worlds-Smartest/`) after user approval.
